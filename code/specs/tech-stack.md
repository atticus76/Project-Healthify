# Tech Stack

Our project is a web application, written through a framework called Reflex, which is written in Python and eventually compiles into React Javascript components and ends up as a project in the React framework. To manage our environment variables and secrets, including our Client ID, secret, and token for the Google Health API OAuth, we are using the python-dotenv library as this works relatively easily for managing those basic variables and allows us to keep everything in our project in Python. In addition to that, we use the requests python library for making and handling the responses of API calls (HTTP GET calls). We plan to set up a backend in Sprint 2, for which we'll likely use SQLite for connecting to some kind of Postgres instance. Likely we will use Docker and some kind of dockerfile for setting up our Docker image, including the Postgres instance, installing the correct version of Python and the Reflex version.
